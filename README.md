## Highlights

**Performance**

Next.js image optimization, optimized font loading, and package-level optimizations keep the site fast without adding unnecessary complexity.

**SEO**

The site includes structured metadata, `robots.txt`, a dynamic sitemap, and JSON-LD structured data.

**Responsive Design**

The interface is designed to work naturally across desktop, tablet, and mobile rather than treating mobile as an afterthought.

**Architecture**

The codebase keeps content and configuration separate from UI logic, with reusable components, custom hooks, and shared utilities.

## Getting Started

### Clone

```bash
git clone https://github.com/alan-shabrandi/portfolio.git
cd portfolio
```

### Install dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
```

### Start the development server

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
